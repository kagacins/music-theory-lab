## Architecture Decisions

### **Why Use a Bridge Layer?**

Instead of rewriting `melodyGenerator.js` immediately, we created a bridge because:

1. **Backward Compatibility**: Existing code continues to work
2. **Gradual Migration**: Can migrate rendering piece by piece
3. **Feature Flag**: Can toggle new system on/off
4. **Risk Mitigation**: If issues arise, can revert easily
5. **Parallel Development**: Old and new systems coexist

### **Bridge Will Eventually Be Removed**

Once `melodyGenerator.js` is fully migrated to use `CompositionState` directly, the bridge can be removed. Timeline: Phase 1C or 2.
